# ☕ cafe-landing

가상의 동네 카페 **"모닝빈"**을 소개하는 한 페이지짜리 랜딩 페이지입니다.
HTML과 CSS만으로 만들었고, 별도의 빌드 도구나 설치 과정 없이 바로 열어볼 수 있습니다.

## 이 폴더는 무엇인가요?

카페 홍보용 웹페이지의 기본 틀입니다. 실제 카페 정보로 문구·가격·주소만 바꾸면 그대로 사용할 수 있도록 단순하게 구성했습니다.

## 페이지 구성

| 섹션 | 내용 |
| --- | --- |
| 상단 메뉴 | 로고, 소개 / 메뉴 / 오시는 길로 이동하는 링크 (스크롤해도 고정) |
| 히어로 | 커피 배경 이미지 위 대표 문구와 "메뉴 보기" 버튼 |
| 모닝빈 이야기 | 매일 로스팅 · 직접 굽는 디저트 · 편안한 공간 (카드 3개) |
| 시그니처 메뉴 | 음료·디저트 6종과 가격 |
| 오시는 길 | 영업시간, 주소, 연락처 |
| 푸터 | 저작권 표기 |

## 파일 구조

```
cafe-landing/
├── index.html   # 페이지 구조와 내용
├── style.css    # 색상, 글꼴, 레이아웃 등 스타일
└── README.md    # 이 문서
```

## 보는 방법

- **내 컴퓨터에서:** `index.html` 파일을 더블클릭해 브라우저로 엽니다.
- **웹에서:** GitHub Pages를 켜면 `https://jinnylee0204-afk.github.io/cafe-landing/` 에서 볼 수 있습니다.

## 수정하는 방법

- **문구·메뉴·가격·주소:** `index.html`에서 해당 텍스트를 바꿉니다.
- **색상:** `style.css` 맨 위 `:root`의 색상 값(`--accent` 등)을 바꾸면 전체 톤이 함께 바뀝니다.
- **배경 이미지:** `style.css`의 `.hero` 안 이미지 주소를 원하는 사진으로 교체합니다.

## 참고

- 주소(`서울시 어딘가구 커피로 12`)와 전화번호(`02-000-0000`)는 임시 값입니다.
- 배경 사진은 Unsplash 이미지를 링크로 불러오며, 글꼴은 Google Fonts(Gowun Batang, Noto Sans KR)를 사용합니다.
- 화면 폭에 맞춰 레이아웃이 조정되어 휴대폰에서도 볼 수 있습니다.
